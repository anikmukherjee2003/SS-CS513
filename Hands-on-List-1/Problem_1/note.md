# Problem 1: Creating Different File Types

## Problem statement
Use shell commands and system calls to create a symbolic link, a hard link, and a FIFO.

## Key calls
- `symlink()` for a symbolic link
- `link()` for a hard link
- `mkfifo()` or `mknod()` for a FIFO

## Execution
Compile and run each C program from this directory. The shell script demonstrates the equivalent shell commands.
