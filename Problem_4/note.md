# Problem 4: Opening an Existing File

## Problem statement
Open an existing file in read-write mode and experiment with the `O_EXCL` flag.

## Key calls and flags
- `open()`
- `O_RDWR`
- `O_EXCL`
- `O_CREAT`

## Execution
Compile and run the program with an existing and a missing file to observe exclusive-open behavior.
